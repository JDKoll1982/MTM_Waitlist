# Database Ruleset Baseline
- Engine: MySQL 5.7.
- IDs: BIGINT internal PK + UUID public id.
- Core startup tables: users, workstations, sessions, roles, role_assignments, startup_logs, system_settings.
- Session tokens: salted hash only; never plaintext.
- Time: UTC and DATETIME for expiry; DB function `fn_server_utc_now` for server-time checks.
- Workstation uniqueness: hostname+MAC composite unique key.
- Lifecycle: hard delete policy; history table for settings change audit.
- Environments: strict dev/test/prod separation; masked synthetic seed data for non-prod.
- Migration governance: Hybrid EF + DBA-reviewed SQL + rollback scripts.
